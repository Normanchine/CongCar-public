## 1. 物理参数测量

### 1.1 轴距 (car_length)

**参数位置**: `ControlConfig.car_length`

**测量方法**:
```
1. 将车放在平地上
2. 找到前轮的中心点（车轴位置）
3. 找到后轮的中心点（车轴位置）
4. 用直尺测量两个中心点的水平距离
```

**测量示意**:
```
        前轴
          ↓
    ┌─────●─────┐
    │           │
    │   车身    │ ← 测量这段距离
    │           │
    └─────●─────┘
          ↑
        后轴
```

**典型值**:
- 智能车竞赛小型车: 0.30 - 0.35 米
- 你的车: 0.316 米

**注意事项**:
- 测量时要确保车轮处于直线状态
- 多次测量取平均值

---

### 1.2 车底中心比例 (car_cy_ratio)

**参数位置**: `ControlConfig.car_cy_ratio`

**含义**: **鸟瞰图中**车底中心的Y坐标比例

**重要说明**:
- 这个参数是在**透视变换后的鸟瞰图**中使用的
- 不是在原始图像中测量
- 摄像头平视或俯视都可以使用

**测量方法**:

**方法1: 运行程序查看鸟瞰图（推荐）**
```
步骤：
1. 先完成透视标定（见第3章）
2. 编译运行程序
3. 浏览器查看视频流（http://192.168.1.100:5001）
4. 观察PIP（画中画）中的鸟瞰图
5. 在鸟瞰图中找到车底位置
6. 估计车底中心距离图像底部的距离
7. 计算比例
```

**计算公式**:
```
car_cy_ratio = (鸟瞰图高度 - 车底距底部距离) / 鸟瞰图高度
```

**示例计算**:
```
假设：
- 鸟瞰图高度 = 480 像素
- 车底中心距离底部 = 24 像素

则：
car_cy_ratio = (480 - 24) / 480 = 456 / 480 = 0.95
```

**方法2: 根据摄像头安装高度估算**
```
经验值：
- 摄像头安装较高 → car_cy_ratio = 0.90-0.92
- 摄像头安装较低 → car_cy_ratio = 0.95-0.98
- 摄像头平视 → 建议先用0.95
```

**鸟瞰图示意**:
```
鸟瞰图坐标系（Y轴向下）：
┌─────────────────────┐ y=0 (图像顶部)
│                     │
│      赛道前方       │
│                     │
│                     │
│                     │
│                     │
│        车底         │ ← cy = h * 0.95 (接近底部)
└─────────────────────┘ y=h (图像底部)
```

**典型值**:
- 一般范围: 0.90 - 0.98
- 你的车: 0.95

**调试建议**:
- 值过大（0.98）→ 转向迟缓，容易冲出赛道
- 值过小（0.90）→ 转向过度，容易震荡
- 值正确 → 车辆平稳跟踪中线

**注意事项**:
- 必须先完成透视标定
- 摄像头位置改变后需要重新测量
- 根据实际控制效果微调

---

### 1.3 近前视距离 (aim_dist_near)

**参数位置**: `ControlConfig.aim_dist_near`

**含义**: 纯跟踪算法的近前视距离

**测量方法**:
```
1. 在赛道上放置一个标记点
2. 车辆以低速行驶
3. 观察车辆开始转向的提前量
4. 测量这个距离
```

**典型值**:
- 一般范围: 0.30 - 0.50 米
- 你的车: 0.35 米

**调试建议**:
- 弯道多、曲率大 → 减小前视距离
- 直道多、速度快 → 增大前视距离

---

## 2. 舵机PWM参数测量

### 2.1 PWM中值 (pwm_mid)

**参数位置**: `ControlConfig.pwm_mid`

**含义**: 舵机中位（直线行驶）时的PWM值

**测量方法**:
```
方法1: 使用舵机测试工具
1. 连接舵机到测试工具
2. 调节PWM值，直到舵机输出轴处于中位
3. 记录PWM值

方法2: 实车测试
1. 将车轮放在平地上
2. 发送不同的PWM值
3. 找到车轮正好指向正前方的PWM值
```

**典型值**:
- 标准舵机: 1500
- 你的车: 1500

**注意事项**:
- 不同舵机可能有差异
- 舵机安装角度会影响中位值

---

### 2.2 PWM范围 (pwm_min, pwm_max)

**参数位置**: `ControlConfig.pwm_min`, `ControlConfig.pwm_max`

**含义**: 舵机的最小和最大PWM值

**测量方法**:
```
1. 从pwm_mid开始
2. 逐渐减小PWM值，直到舵机到达左极限
3. 记录pwm_min
4. 逐渐增大PWM值，直到舵机到达右极限
5. 记录pwm_max
```

**典型值**:
- 标准范围: 500 - 2500
- 你的车: 500 - 2500

**注意事项**:
- 不要超过舵机物理极限，否则会损坏
- 留出安全余量（例如±50）

---

### 2.3 PWM缩放系数 (pwm_k)

**参数位置**: `ControlConfig.pwm_k`

**含义**: 将"经过PD放大后的航向误差（弧度）"转换为"PWM变化量"的增益系数

**重要说明**:
- 航向误差是**弧度值**，不是角度值
- `pwm_k` 是一个经验系数，需要通过实际调试确定
- 理论计算值与实际调试值可能差异很大

**理论计算（仅供参考）**:
```
假设：
- 最大转向角 = 38° = 0.663 弧度
- PWM变化范围 = 1000（从中位到极限）

则：
pwm_k = 1000 / 0.663 ≈ 1508
```

**实际调试方法**:
```
步骤：
1. 设置初始值：pwm_k = 1000, pid_p = 1.0, pid_d = 0
2. 观察航向误差范围（通常 0.01 - 0.1 rad）
3. 观察PWM变化范围
4. 根据效果调整：
   - 转向不够 → 增大 pwm_k
   - 转向过度 → 减小 pwm_k
5. 结合 pid_p 和 pid_d 一起调试
```

**调试建议**:
- **转向过于灵敏** → 减小 pwm_k 或减小 pid_p
- **转向不够灵敏** → 增大 pwm_k 或增大 pid_p
- **出现震荡** → 减小 pid_p 或增大 pid_d

**典型值范围**:
- 理论值：1000 - 2000
- 实际调试值：20 - 100（根据 pid_p 调整）
- 你的车：30.0

**注意事项**:
- pwm_k 与 pid_p 相互影响，需要一起调试
- 不同速度下可能需要不同的 pwm_k
- 建议先调 pid_p，再调 pwm_k

---

### 2.4 PWM中位 (pwm_neutral)

**参数位置**: `UartConfig.pwm_neutral`

**含义**: 程序退出时舵机回到的PWM值

**测量方法**:
```
与pwm_mid相同，通常设置为舵机中位值
```

**典型值**:
- 与pwm_mid相同: 1500

## 3. 透视标定参数

### 3.1 透视源四点 (src_quad)

**参数位置**: `CalibConfig.src_quad`

**含义**: 赛道在图像中的四个角点坐标

**测量方法**:
```
使用标定工具：tools/calibrate_perspective.py

步骤：
1. 拍摄赛道照片
2. 运行标定工具
3. 点击赛道四个角点（左上、右上、右下、左下）
4. 工具自动生成src_quad
```

**使用命令**:
```bash
cd Car
python tools/calibrate_perspective.py track.jpg config/default.json
```

**标定示意**:
```
图像坐标系：
┌─────────────────────┐
│  0──────1           │
│  │      │           │
│  │ 赛道 │           │
│  │      │           │
│  3──────2           │
└─────────────────────┘

点击顺序：0 → 1 → 2 → 3
```

**注意事项**:
- 四个点必须按顺序点击
- 选择赛道边缘清晰的位置
- 摄像头位置改变后需要重新标定

---

### 3.2 像素/米比例 (ppm_x, ppm_y)

**参数位置**: `CalibConfig.ppm_x`, `CalibConfig.ppm_y`

**含义**: 图像像素到物理距离的转换比例

**测量方法**:
```
方法1: 使用标定工具
1. 在标定工具中输入赛道实际宽度
2. 工具自动计算ppm

方法2: 手动测量
1. 在赛道上放置已知长度的物体
2. 在图像中测量该物体的像素长度
3. 计算比例：ppm = 像素长度 / 实际长度
```

**示例计算**:
```
假设：
- 赛道实际宽度 = 0.45 米
- 图像中赛道宽度 = 100 像素

则：
ppm_x = 100 / 0.45 ≈ 222.22 像素/米
```

**典型值**:
- 智能车赛道: 200 - 250 像素/米
- 你的车: 222.22

## 4. 串口配置参数

### 4.1 串口设备 (port)

**参数位置**: `UartConfig.port`

**查找方法**:
```bash
# 查看所有串口设备
ls /dev/ttyUSB*

# 查看USB设备详情
dmesg | grep ttyUSB

# 查看设备权限
ls -l /dev/ttyUSB0
```

**常见设备名**:
- USB转串口: `/dev/ttyUSB0`, `/dev/ttyUSB1`
- 板载串口: `/dev/ttyS0`, `/dev/ttyS1`

**注意事项**:
- 如果有多个USB设备，需要确认哪个是下位机
- 可能需要添加串口权限：
  ```bash
  sudo usermod -a -G dialout $USER
  ```

---

### 4.2 波特率 (baud)

**参数位置**: `UartConfig.baud`

**确认方法**:
```
1. 查看下位机程序中的波特率设置
2. 确保上位机和下位机波特率一致
```

**常见波特率**:
- 9600
- 115200（常用）
- 230400

**你的配置**: 115200

## 5. 控制参数调试

### 5.1 最大速度 (max_speed)

**参数位置**: `SceneControlParams.max_speed`

**调试方法**:
```
1. 从低速开始（0.1 m/s）
2. 观察车辆稳定性
3. 逐渐提高速度
4. 找到车辆能稳定行驶的最大速度
```

**调试建议**:
- 弯道多 → 降低速度
- 直道多 → 提高速度
- 留出安全余量

---

### 5.2 PID参数 (pid_p, pid_d)

**参数位置**: `SceneControlParams.pid_p`, `SceneControlParams.pid_d`

**调试方法**:
```
1. 先调P，D=0
   - 从小值开始（例如0.5）
   - 观察转向响应
   - 逐渐增大直到出现震荡

2. 再调D
   - 从小值开始（例如0.1）
   - 观察震荡是否减小
   - 逐渐增大直到响应平滑

3. 微调
   - 在不同速度下测试
   - 在不同弯道下测试
```

**典型值范围**:
- pid_p: 0.5 - 3.0
- pid_d: 0.1 - 1.0

**调试技巧**:
- P过大 → 震荡、摆动
- P过小 → 转向不足
- D过大 → 转向迟缓
- D过小 → 震荡

---

### 5.3 动态前视系数 (lookahead_speed_k)

**参数位置**: `ControlConfig.lookahead_speed_k`

**含义**: 前视距离随速度动态调整的系数

**公式**: `前视距离 = aim_dist_near + 当前速度 × lookahead_speed_k`

**调试方法**:
```
1. 从0开始（即固定前视距离）
2. 逐渐增大（例如0.05、0.10、0.15）
3. 观察高速过弯时的表现
```

**调试建议**:
- 值越大 → 高速时看得越远，直道更稳
- 值越小 → 高速时前视变化不大，弯道更灵活
- 典型值: 0.10 - 0.20
- 默认值: 0.15

---

### 5.4 丢线容错帧数 (max_lost_frames)

**参数位置**: `ControlConfig.max_lost_frames`

**含义**: 赛道短暂丢失时容忍的最大帧数，超过此帧数才执行停车保护

**调试方法**:
```
1. 从较小值开始（例如3帧）
2. 观察赛道闪烁时的表现
3. 增大直到不会因短暂丢线而误停车
```

**调试建议**:
- 值过小 → 短暂丢线就停车，比赛容易中断
- 值过大 → 丢线后长时间盲开，可能冲出赛道
- 典型值: 3 - 10 帧（约0.1-0.3秒）
- 默认值: 5

---

### 5.5 盲开速度衰减 (coast_speed_decay)

**参数位置**: `ControlConfig.coast_speed_decay`

**含义**: 赛道丢失后每帧速度乘以的衰减系数（指数衰减）

**公式**: `新速度 = 上一帧速度 × coast_speed_decay`

**调试方法**:
```
1. 从0.9开始
2. 观察盲开时速度下降的速度
3. 调整到合适的衰减速率
```

**调试建议**:
- 值接近1.0（如0.95）→ 速度衰减慢，盲开时间更长
- 值较小（如0.8）→ 速度衰减快，快速降速
- 典型值: 0.85 - 0.95
- 默认值: 0.9

---

### 5.6 横向赛道入轨转向 (track_search_turn_dir)

**参数位置**: `ControlConfig.track_search_turn_dir`

**含义**: 垂直面对横向赛道时，默认的入轨转弯方向

**取值**:
- `1` → 向右转进入赛道
- `-1` → 向左转进入赛道

**调试方法**:
```
1. 观察垂直发车时赛道在车身哪一侧
2. 赛道在右侧 → 设置为1
3. 赛道在左侧 → 设置为-1
```

**典型值**: 1（默认向右）

**注意事项**:
- 仅在垂直发车场景（赛道横向）时生效
- 常规纵向赛道不需要关心此参数

## 6. 测量流程建议

### 6.1 新车调试流程

```
第1步: 物理参数测量
├── 测量轴距
├── 测量车底中心比例
└── 确定前视距离

第2步: 舵机PWM标定
├── 测量PWM中值
├── 测量PWM范围
└── 计算PWM缩放系数

第3步: 透视标定
├── 拍摄赛道照片
├── 运行标定工具
└── 生成标定参数

第4步: 串口配置
├── 确认串口设备
└── 确认波特率

第5步: 控制参数调试
├── 低速调试PID
├── 调整动态前视系数
├── 设置丢线容错参数
├── 提高速度
└── 优化参数
```

---

### 6.2 参数更新流程

```
1. 修改配置文件
   vim config/default.json

2. 重新编译（如果修改了Config.h）
   cd Car/build && make -j8

3. 测试运行
   ./car ../config/default.json

4. 观察效果
   - 浏览器查看视频流
   - 观察控制台性能统计
   - 检查串口通信

5. 迭代优化
   - 根据实际效果调整参数
   - 重复步骤1-4
```

## 7. 常见问题排查

### 7.1 转向问题

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 车辆不走直线 | pwm_mid不正确 | 重新测量舵机中位 |
| 转向幅度不够 | pwm_k过小 | 增大pwm_k |
| 转向震荡 | pid_p过大 | 减小pid_p或增大pid_d |
| 转向迟缓 | pid_p过小 | 增大pid_p |

---

### 7.2 视觉问题

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 鸟瞰图变形 | src_quad标定错误 | 重新标定透视 |
| 距离计算错误 | ppm不正确 | 重新测量ppm |
| 车底位置不准 | car_cy_ratio错误 | 重新测量车底中心 |

---

### 7.3 通信问题

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 串口打开失败 | 设备名错误 | 检查/dev/ttyUSB* |
| 通信乱码 | 波特率不匹配 | 确认双方波特率一致 |
| 权限不足 | 用户不在dialout组 | 添加用户到dialout组 |

---

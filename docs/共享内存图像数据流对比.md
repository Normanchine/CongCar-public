# 共享内存图像数据流对比

> ar_receiver.py / Car — 两者的共享内存读取→图像处理的完整链路

## 共享内存格式（两者一致）

```
[0..7]  fid   uint64   帧序号
[8..11] w     uint32   图像宽度
[12..15] h    uint32   图像高度
[16..]  裸RGB数据  w*h*3 字节, row-major, 从上到下（Python端已做flip(0)）
```

## 数据流对比

```
               ar_receiver.py            Car(CaptureTask+DisplayTask)
               ═════════════             ════════════════════════════

①连接          multiprocessing.SHM       POSIX shm_open+mmap
                                         支持断线重连

②读Header      struct.unpack('QII')      std::memcpy (同)

③去重          fid==last? sleep 2ms      fid==last? 自适应sleep
                                         (根据实时FPS调节)

④深拷贝        np.view → .copy()          cv::Mat + std::memcpy

⑤垂直翻转      cv2.flip(0)                cv::flip(0)

⑥★色域处理★    RGB → BGR（立即转）        保持 RGB 全程不变
               ar_receiver.py:67

⑥帧裁剪        —                          frame_crop: 可裁剪(默认开)

⑦分割预处理    —（不做分割）              resize→512×256 RGB
                                         → segmentation_queue

⑧检测预处理    全帧BGR → infer()          resize→640×256 RGB
                                         → detection_queue

⑨模型推理      RKNN (RGB UINT8)           RKNN (RGB UINT8)
               func.py:236 BGR→RGB转回    NPU Core0/Core1+Core2 分别推理

⑩后处理        YOLOv5 decode+NMS         PP-YOLOE decode+NMS
               draw到BGR原图上            seg: argmax→resize→工作帧
                                         坐标映射到frame_width×frame_height

⑪路径规划      —                          SceneManager: NormalScene/CarScene/
                                          PersonScene/RLightScene/TrafficSignScene
                                          PathFollower: 透视→中线→PD→速度

⑫显示/推流     cv2.imshow (BGR)          HTTP MJPEG推流
                                         推流前 RGB→BGR 转一次

⑬架构          单线程                     5线程流水线
               (读→推理→显示顺序)          (采集/分割/检测/控制/显示并行)
```

## 核心差异总结

| 差异点 | ar_receiver.py | Car |
|--------|:---:|:---:|
| 色域策略 | RGB→BGR→RGB 来回转 | RGB全程直传 |
| 色域转换次数 | **2次** | **1次**（仅推流前） |
| 帧裁剪 | 无 | frame_crop 可选 |
| 检测后处理 | YOLOv5 | PP-YOLOE (7类自定义) |
| 语义分割 | — | Core1+Core2 双核流水线 |
| 线程模型 | 单线程 | 5线程流水线 |

## 色域转换路径精要

```
ar_receiver:  SHM(RGB) → flip → RGB→BGR → infer入口 → BGR→RGB → NPU → draw(BGR) → imshow(BGR)
                                  ↑                        ↑
                              ar_receiver.py:67        func.py:236

Car:          SHM(RGB) → flip → resize → NPU(RGB) → ... → RGB→BGR → JPEG推流
                                                              ↑
                                                         仅此一次
```

**两者送入NPU模型的都是 RGB UINT8**,但 ar_receiver.py 在中间多走了一趟 RGB→BGR→RGB 的冤枉路。

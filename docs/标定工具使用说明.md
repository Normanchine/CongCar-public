# 透视变换标定工具使用说明

> 版本: v1.1 | 更新时间: 2026-07-01

---

## 一、标定目的

透视变换标定用于将相机拍摄的透视图像转换为鸟瞰图（俯视图），主要作用：

1. **消除透视畸变**：相机拍摄的图像存在近大远小的透视效应，标定后可转换为正交投影
2. **距离测量**：通过PPM（Pixels Per Meter）参数，可将图像像素坐标转换为真实世界坐标
3. **路径规划**：鸟瞰图更适合进行路径规划和导航算法

---

## 二、标定原理

### 2.1 透视变换原理

透视变换（Perspective Transformation）通过4对对应点建立映射关系：

```
原图坐标系 (x,y) → 鸟瞰图坐标系 (x',y')
```

变换公式：
```
x' = (M[0][0]*x + M[0][1]*y + M[0][2]) / (M[2][0]*x + M[2][1]*y + M[2][2])
y' = (M[1][0]*x + M[1][1]*y + M[1][2]) / (M[2][0]*x + M[2][1]*y + M[2][2])
```

其中 M 为 3×3 变换矩阵，通过 OpenCV 的 `cv::getPerspectiveTransform()` 计算。

### 2.2 PPM 计算

**PPM（Pixels Per Meter）**：每米对应的像素数，用于像素距离与真实距离的转换。

```
PPM_X = 鸟瞰图宽度 / 实际宽度 (px/m)
PPM_Y = 鸟瞰图高度 / 实际长度 (px/m)
```

**注意**：由于相机安装角度和镜头畸变，X和Y方向的PPM可能不同。

## 三、标定工具

### 3.1 工具列表

| 工具名称 | 路径 | 用途 | 运行脚本 |
|---------|------|------|---------|
| **car_calib** | `Car/tools/calibrate.cpp` | Car项目标定 | `run_calibrate.sh` |

### 3.2 运行方式

#### 方式一：从共享内存读取实时帧（推荐）

```bash
./run_calibrate.sh                           # 使用默认配置 Car/config/default.json
./run_calibrate.sh Car/config/default.json   # 指定配置文件
```

**前提条件**：
- Python 视频推流服务已启动
- 共享内存 `shm_ar_video` 已创建

#### 方式二：从图片文件读取

```bash
./run_calibrate.sh track.jpg                 # 使用默认配置
./run_calibrate.sh track.jpg custom.json     # 指定配置文件
```

## 四、标定流程

### 步骤1：获取图像

**从共享内存读取**：
- 工具自动连接共享内存 `shm_ar_video`
- 等待有效帧（最多1秒）
- 自动垂直翻转（因为共享内存数据是倒置的）

**从图片文件读取**：
- 直接读取指定路径的图片文件

### 步骤2：选择四角点

1. 工具显示图像窗口
2. 鼠标按顺序点击4个角点：
   - **左上** → **右上** → **右下** → **左下**
3. 点击过程中实时显示已选点和连线
4. 4个点选择完成后自动进入下一步

**操作提示**：
- 点击位置应为赛道边界的四个角
- 点击顺序必须是顺时针或逆时针
- 按 `r` 重置所有点
- 按 `z` 撤销上一个点
- 按 `q` 退出

### 步骤3：输入参数

工具提示输入以下参数：

1. **鸟瞰图宽度**（像素）：建议 240-640
2. **鸟瞰图高度**（像素）：建议 480
3. **实际宽度**（米）：赛道实际宽度，如 0.45
4. **实际高度**（米）：视野实际高度，如 0.8

### 步骤4：预览确认

- 工具显示变换后的鸟瞰图
- 检查变换效果是否正确
- 按 `y` 确认，按 `n` 重新标定

### 步骤5：写入配置

工具自动将标定参数写入配置文件的 `calib` 段：

```json
"calib": {
    "src_quad": [x0, y0, x1, y1, x2, y2, x3, y3],
    "bird_width": 240,
    "bird_height": 480,
    "bird_width_scale": 1.0,
    "ppm_x": 600.0,
    "ppm_y": 600.0
}
```

---

## 五、配置参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `src_quad` | float[8] | 原图四角点坐标 [x0,y0, x1,y1, x2,y2, x3,y3] |
| `bird_width` | int | 鸟瞰图宽度（像素） |
| `bird_height` | int | 鸟瞰图高度（像素） |
| `bird_width_scale` | float | 鸟瞰图宽度扩展倍数（>1扩大视野，ppm不变） |
| `ppm_x` | float | X方向像素/米 |
| `ppm_y` | float | Y方向像素/米 |

## 六、验证标定效果

### 6.1 运行主程序验证

```bash
cd Car/Car/build
./car
```

观察：
- 鸟瞰图是否正确显示
- 赛道边线是否平行
- 中线提取是否正确

### 6.2 检查PPM

如果距离测量不准确，调整 `ppm_x` 和 `ppm_y`：

```
新PPM = 旧PPM × (测量值 / 实际值)
```

## 七、常见问题

### Q1: 鸟瞰图变形严重

**原因**：四角点选择不准确

**解决**：
- 重新标定，确保点击的是赛道边界角点
- 确保点击顺序正确（左上→右上→右下→左下）

### Q2: 鸟瞰图宽度比例不对

**原因**：`bird_width_scale` 设置不当

**解决**：
- `bird_width_scale = 1.0`：标准宽度
- `bird_width_scale > 1.0`：扩大视野（适合弯道）
- `bird_width_scale < 1.0`：缩小视野

### Q3: 距离测量不准

**原因**：PPM参数不准确

**解决**：
- 在鸟瞰图中测量已知距离
- 计算实际PPM并更新配置

### Q4: 工具无法连接共享内存

**原因**：Python视频服务未启动

**解决**：
```bash
# 启动Python视频服务
python video_service.py
```

## 八、标定技巧

1. **选择明显角点**：选择赛道边界的明显角点，避免模糊位置
2. **保持水平**：确保相机安装水平，减少标定误差
3. **多次标定**：多次标定取平均值，提高精度
4. **现场标定**：在比赛现场重新标定，适应环境变化
5. **保存备份**：标定完成后备份配置文件

## 九、标定参数参考

### 典型参数值

| 参数 | 典型值 | 说明 |
|------|--------|------|
| `bird_width` | 240-640 | 根据赛道宽度调整 |
| `bird_height` | 480-640 | 根据视野高度调整 |
| `ppm_x` | 500-800 | 根据相机高度和角度 |
| `ppm_y` | 500-800 | 根据相机高度和角度 |
| `bird_width_scale` | 1.0-1.5 | 弯道多时增大 |

### 参数计算公式

```
ppm_x = bird_width / 实际宽度 (米)
ppm_y = bird_height / 实际高度 (米)
```

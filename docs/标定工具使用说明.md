# 透视变换标定工具使用说明

> 版本: v1.0 | 更新时间: 2026-06-06

---

## 一、标定目的

透视变换标定用于将相机拍摄的透视图像转换为鸟瞰图（俯视图），主要作用：

1. **消除透视畸变**：相机拍摄的图像存在近大远小的透视效应，标定后可转换为正交投影
2. **距离测量**：通过PPM（Pixels Per Meter）参数，可将图像像素坐标转换为真实世界坐标
3. **路径规划**：鸟瞰图更适合进行路径规划和导航算法

---

## 二、标定原理

### 2.1 透视变换原理

透视变换（Perspective Transformation）通过4对对应点建立映射关系：

```
原图坐标系 (x,y) → 鸟瞰图坐标系 (x',y')
```

变换公式：
```
x' = (M[0][0]*x + M[0][1]*y + M[0][2]) / (M[2][0]*x + M[2][1]*y + M[2][2])
y' = (M[1][0]*x + M[1][1]*y + M[1][2]) / (M[2][0]*x + M[2][1]*y + M[2][2])
```

其中 M 为 3×3 变换矩阵，通过 OpenCV 的 `cv::getPerspectiveTransform()` 计算。

### 2.2 PPM 计算

**PPM（Pixels Per Meter）**：每米对应的像素数，用于像素距离与真实距离的转换。

```
PPM_X = 鸟瞰图宽度 / 实际宽度 (px/m)
PPM_Y = 鸟瞰图高度 / 实际长度 (px/m)
```

**注意**：由于相机安装角度和镜头畸变，X和Y方向的PPM可能不同。

## 三、标定工具

### 3.1 工具列表

| 工具名称 | 路径 | 用途 | 运行脚本 |
|---------|------|------|---------|
| **simble_calib** | `simble/calibrate.cpp` | simble项目标定 | `run_simble_calib.sh` |
| **car_calib** | `Car/tools/calibrate.cpp` | Car项目标定 | `run_calibrate.sh` |

### 3.2 运行方式

#### 方式一：从共享内存读取实时帧（推荐）

```bash
# simble项目
./run_simble_calib.sh                        # 使用默认配置 simble/config.json
./run_simble_calib.sh simble/config.json     # 指定配置文件

# Car项目
./run_calibrate.sh                           # 使用默认配置 Car/config/default.json
./run_calibrate.sh Car/config/default.json   # 指定配置文件
```

**前提条件**：
- Python 视频推流服务已启动
- 共享内存 `shm_ar_video` 已创建

#### 方式二：从图片文件读取

```bash
# simble项目
./run_simble_calib.sh track.jpg              # 使用默认配置
./run_simble_calib.sh track.jpg my.json      # 指定配置文件

# Car项目
./run_calibrate.sh track.jpg                 # 使用默认配置
./run_calibrate.sh track.jpg custom.json     # 指定配置文件
```

## 四、标定流程

### 步骤1：获取图像

**从共享内存读取**：
- 工具自动连接共享内存 `shm_ar_video`
- 等待有效帧（最多1秒）
- 自动垂直翻转（因为共享内存数据是倒置的）

**从图片文件读取**：
- 直接读取指定路径的图片文件

### 步骤2：选择4个角点

在图像上用鼠标依次点击4个角点：

```
点击顺序：左上 → 右上 → 右下 → 左下
```

**操作提示**：
- 点击后会显示红色圆点标记
- 选完2个点后会显示绿色连线
- 选完4个点后会显示完整的四边形
- 按 **ESC** 可重新选择

**选点技巧**：
- 选择一个矩形区域（如赛道、地砖）
- 确保四个角点清晰可见
- 尽量选择较大的区域以提高精度

### 步骤3：输入鸟瞰图尺寸

程序会提示输入：

```
图片原始尺寸: 1920 x 1080
鸟瞰图宽度 (推荐 640): [输入或回车使用默认值]
鸟瞰图高度 (推荐 480): [输入或回车使用默认值]
```

**推荐值**：
- 宽度：640 像素
- 高度：480 像素

**选择原则**：
- 保持宽高比与实际物理宽高比一致
- 不宜过大（影响性能）或过小（影响精度）

### 步骤4：输入实际物理尺寸

程序会提示输入：

```
所选区域实际宽度 (米, 如 1.0): [输入实际宽度]
所选区域实际长度 (米, 如 2.0): [输入实际长度]
```

**测量方法**：
- 使用卷尺测量所选区域的实际宽度和长度
- 单位：米
- 尽量精确到厘米级

**示例**：
```
所选区域实际宽度: 0.8   # 80厘米宽
所选区域实际长度: 1.5   # 150厘米长
```

### 步骤5：预览效果

程序会显示对比图：

```
左侧：原图（缩放到鸟瞰图尺寸）
右侧：鸟瞰图（透视变换结果）
```

**操作**：
- 按 **任意键** 确认标定结果
- 按 **ESC** 重新标定

**检查要点**：
- 鸟瞰图中的直线是否保持笔直
- 矩形区域是否变形为标准矩形
- 边缘是否过度拉伸或压缩

### 步骤6：保存配置

标定参数自动写入配置文件的 `calib` 字段：

```json
"calib": {
  "src_quad": [123, 456, 789, 456, 789, 987, 123, 987],
  "bird_width": 640,
  "bird_height": 480,
  "ppm_x": 800.0,
  "ppm_y": 320.0
}
```

**参数说明**：

| 参数 | 类型 | 说明 |
|------|------|------|
| `src_quad` | float[8] | 原图4个角点坐标 [x0,y0, x1,y1, x2,y2, x3,y3] |
| `bird_width` | int | 鸟瞰图宽度（像素） |
| `bird_height` | int | 鸟瞰图高度（像素） |
| `ppm_x` | float | X方向像素/米比例（水平方向） |
| `ppm_y` | float | Y方向像素/米比例（垂直方向） |

## 七、常见问题

### Q1: 共享内存连接失败

**错误信息**：
```
[错误] 无法打开共享内存: shm_ar_video
[提示] 请确保 Python 视频推流服务已启动
```

**解决方法**：
1. 检查Python视频推流服务是否启动
2. 确认共享内存名称是否正确（配置文件中的 `shm_name`）
3. 检查共享内存大小配置（`shm_size`）

### Q2: 鸟瞰图变形严重

**可能原因**：
- 角点选择不准确
- 实际物理尺寸测量误差大
- 相机镜头畸变严重

**解决方法**：
1. 重新选择角点，确保顺序正确（左上→右上→右下→左下）
2. 精确测量实际物理尺寸
3. 考虑先进行相机畸变校正

### Q3: PPM值异常

**正常范围**：
- PPM_X：通常 500-1500 px/m
- PPM_Y：通常 200-800 px/m

**异常情况**：
- PPM = 0：未完成标定
- PPM 过大或过小：实际尺寸测量错误

**验证方法**：
```
实际距离(米) = 像素距离 / PPM
```

### Q4: 标定后距离测量不准

**排查步骤**：
1. 检查 `src_quad` 坐标是否正确
2. 验证 PPM 计算：`PPM = 鸟瞰图尺寸 / 实际尺寸`
3. 确认相机安装位置和角度未改变
4. 重新标定

## 八、技术细节

### 8.1 共享内存数据格式

```
偏移量    大小    内容
0         8字节   帧ID (uint64_t)
8         4字节   图像宽度 (uint32_t)
12        4字节   图像高度 (uint32_t)
16        N字节   RGB数据 (w * h * 3)
```

### 8.2 透视变换矩阵

变换矩阵 M 为 3×3 矩阵：

```
M = [m00 m01 m02]
    [m10 m11 m12]
    [m20 m21 m22]
```

计算方式：
```cpp
std::vector<cv::Point2f> src_pts = {pt0, pt1, pt2, pt3};  // 原图4点
std::vector<cv::Point2f> dst_pts = {                      // 鸟瞰图4点
    cv::Point2f(0, 0),
    cv::Point2f(bird_w-1, 0),
    cv::Point2f(bird_w-1, bird_h-1),
    cv::Point2f(0, bird_h-1)
};
cv::Mat M = cv::getPerspectiveTransform(src_pts, dst_pts);
```

应用变换：
```cpp
cv::Mat bird_view;
cv::warpPerspective(image, bird_view, M, cv::Size(bird_w, bird_h));
```

### 8.3 坐标转换

**像素坐标 → 世界坐标**：
```cpp
float world_x = pixel_x / ppm_x;  // 单位：米
float world_y = pixel_y / ppm_y;  // 单位：米
```

**世界坐标 → 像素坐标**：
```cpp
int pixel_x = world_x * ppm_x;
int pixel_y = world_y * ppm_y;
```

## 九、注意事项

1. **相机固定**：标定后相机位置和角度不能改变，否则需要重新标定
2. **定期校验**：建议每次比赛前验证标定参数是否准确
3. **保存备份**：标定完成后备份配置文件
4. **环境变化**：光照、地面纹理变化不影响标定参数，但可能影响分割效果
5. **多场景标定**：不同赛道可能需要不同的标定参数

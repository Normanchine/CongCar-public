# 共享内存图像数据流对比

> ar_receiver.py / Car / simble — 三者的共享内存读取→图像处理的完整链路

## 共享内存格式（三者一致）

```
[0..7]  fid   uint64   帧序号
[8..11] w     uint32   图像宽度
[12..15] h    uint32   图像高度
[16..]  裸RGB数据  w*h*3 字节, row-major, 从上到下（Python端已做flip(0)）
```

## 数据流对比

```
               ar_receiver.py            Car(CaptureTask+DisplayTask)      simble
               ═════════════             ════════════════════════════      ══════

①连接          multiprocessing.SHM       POSIX shm_open+mmap              POSIX shm_open+mmap
                                         支持断线重连                      不支持断线重连

②读Header      struct.unpack('QII')      std::memcpy (同)                 std::memcpy (同)

③去重          fid==last? sleep 2ms      fid==last? 自适应sleep            fid==last? sleep 2ms
                                         (根据实时FPS调节)

④深拷贝        np.view → .copy()          cv::Mat + std::memcpy            cv::Mat + std::memcpy

⑤垂直翻转      cv2.flip(0)                cv::flip(0)                      cv::flip(0)

⑥★色域处理★    RGB → BGR（立即转）        保持 RGB 全程不变                 保持 RGB 全程不变
               ar_receiver.py:67                                          (同Car)

⑥帧裁剪        —                          frame_crop: 可裁剪(默认关)          frame_crop: 可裁剪(默认关)
                                                                             flip后立即crop, 更新w/h
                                                                             后续所有处理基于工作帧尺寸

⑦分割预处理    —（不做分割）              resize→seg_w×seg_h RGB            resize→model_w×model_h RGB
                                         → segmentation_queue             → NPU Core2

⑧检测预处理    全帧BGR → infer()          resize→det_w×det_h RGB            resize→det_model_w×det_model_h RGB
                                         → detection_queue                → NPU Core0

⑨模型推理      RKNN (RGB UINT8)           RKNN (RGB UINT8)                 RKNN (RGB UINT8)
               func.py:236 BGR→RGB转回    NPU Core0/Core2 分别推理          NPU Core0/Core2 分别推理

⑩后处理        YOLOv5 decode+NMS         YOLO decode+NMS                  PP-YOLOE decode+NMS
               draw到BGR原图上            seg: argmax→resize→工作帧          seg: argmax→resize→工作帧
                                         坐标映射到frame_width×frame_height 坐标映射到w×h

⑪路径规划      —                          NormalScene:                    main循环内:
                                          透视→中线→动态前视→PD            透视→中线→纯跟踪→headingError

⑫显示/推流     cv2.imshow (BGR)          HTTP MJPEG推流                   HTTP MJPEG推流
                                         推流前 RGB→BGR 转一次             推流前 RGB→BGR 转一次
                                         图片模式: --image 可选

⑬架构          单线程                     5线程流水线                      单线程
               (读→推理→显示顺序)          (采集/分割/检测/控制/显示并行)    (读→分割→检测→路径→显示顺序)
```

## 核心差异总结

| 差异点 | ar_receiver.py | Car | simble |
|--------|:---:|:---:|:---:|
| 色域策略 | RGB→BGR→RGB 来回转 | RGB全程直传 | RGB全程直传 |
| 色域转换次数 | **2次** | **1次**（仅推流前） | **1次**（仅推流前） |
| 帧裁剪 | 无 | frame_crop 可选 | frame_crop 可选 |
| 检测预处理 | 全帧原图 | 全帧resize | 全帧resize |
| 线程模型 | 单线程 | 5线程流水线 | 单线程 |
| 图片推理 | — | — | --image 可选 |

## 色域转换路径精要

```
ar_receiver:  SHM(RGB) → flip → RGB→BGR → infer入口 → BGR→RGB → NPU → draw(BGR) → imshow(BGR)
                                  ↑                        ↑
                              ar_receiver.py:67        func.py:236

Car/simble:   SHM(RGB) → flip → resize → NPU(RGB) → ... → RGB→BGR → JPEG推流
                                                              ↑
                                                         仅此一次
```

**三者送入NPU模型的都是 RGB UINT8**,但 ar_receiver.py 在中间多走了一趟 RGB→BGR→RGB 的冤枉路。
